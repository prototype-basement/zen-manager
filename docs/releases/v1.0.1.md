# ZEN Manager 1.0.1

A bug fix for Linux.

## Fixed

- **Every track showed as "unknown artist" on many Linux systems.** Albums
  showed as "unknown" and titles as filenames. It affected distributions that
  ship libmtp older than 1.1.20: Ubuntu 20.04 and 22.04, Debian 11, elementary
  OS 6 and 7, Linux Mint 20 and 21. Those versions of libmtp have a bug that
  makes one way of reading tags return nothing, silently. ZEN Manager now reads
  them a different way that works on every version.

  Your music was never affected. The tags on the player were correct all along,
  and transfers from Linux wrote them properly. Only the display in ZEN Manager
  was wrong.

## Improved

- **Opening the music list is faster.** Artist, album and title now come from
  the player in one request per track instead of three.

## Tip for Linux

If you see "device is busy" or the Zen sometimes fails to appear, your file
manager has probably claimed it — most Linux desktops open MTP players
automatically. Eject the Zen in your file manager, then open ZEN Manager.
